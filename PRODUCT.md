# SchoolDesk Staff app

Mobile-first staff PWA for SMS Barmer: teachers take attendance, assign/check homework, enter marks, view class schedules and communicate with parents. Staff also access leave, notices, personal attendance and salary records. Driver trip controls and ERP-login modules are separate role contexts in the same app.

The approved StaffHome is the visual authority. This work extends that identity to task screens and shared controls while retaining backend contracts, role access, bilingual English/Hindi copy, and existing home composition. Review uses the existing opt-in demo mode on a separate local port, never live school writes.
